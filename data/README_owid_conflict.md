# Death rate in armed conflicts, 1989–2025 (Organismality Index, conflict axis)

File: `owid_ucdp_death_rate_armed_conflicts.csv`
Columns: Entity, Code, Year, "Death rate in ongoing conflicts (best estimate) - Conflict type: all" (deaths per 100,000 people).

Source: Our World in Data, "Death rate in armed conflicts based on where they occurred",
https://ourworldindata.org/grapher/death-rate-in-armed-conflicts — based on the Uppsala Conflict Data Program (UCDP).
Counts deaths of combatants and civilians due to fighting in interstate, intrastate, extrasystemic and non-state
conflicts and one-sided violence; excludes deaths from disease and starvation. Downloaded 20 Oct 2026. CC BY 4.0 (OWID).

## Weekly refresh
These files are refreshed weekly by `.github/workflows/weekly_refresh.yml`; retrieval dates, hashes and changes are in `data/MANIFEST.json` and `results/weekly/`. Figures quoted in this README are from the 20 Oct 2026 download unless stated otherwise.

Location: each file is in its own folder, `data/sources/<file name without extension>/`; source URL and download date are in `data/MANIFEST.json`.
