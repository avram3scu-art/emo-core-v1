## 2. New findings

### Code

| # | Finding | Sev. |
|---|---|---|
| D3 | **The DAC standard cannot code a multi-level case.** If delivery at the case's primary end point is missing but delivery at a secondary end point is dated, the file is rejected ("sublayer 'delivery' is both dated and missing"). The mpox case (session 10: EU level and countries) needs exactly this. Missing/censored must be keyed by sublayer **and** end point. | B (blocks session 10) |
| D4 | A delivery paired with an order whose date is missing vanishes from `paired_order_to_delivery`; the profile does not say the pair exists but is undatable. Same silent drop risk in session 10. | B |
| D5 | A contested t0 is checked on its first reading only; a second reading coded `lower_bound` passes and makes every lag's lower end open (None). | B |
| D1 | `"standard_version": null` is accepted. | C |
| D2 | Unknown keys inside `case` are accepted (a typo such as `observaton_window` would be caught only because the real key is then missing; an extra misspelt optional key is silent). | C |
| D6 | Order-to-delivery: `unpaired_first_order_to_first_delivery` takes the first order of **any** level against the first delivery at the primary end point. In a multi-level case this mixes EU joint orders with national deliveries. Needs a level/end-point field on orders, decided before coding session 10. | B |
| M1 | **`compute_smf`'s circular-shift null is invalid for trending or unit-root input.** Two independent linear trends "pass" 100% of the time, two independent random walks 32% (nominal 5%). The docstring's "unrelated series therefore score 0 about 95% of the time" is false except for stationary series. The recorded SMF tests used 12-month log changes, which are close to stationary, so their verdicts are not overturned by this; but nothing in the code stops a future use on levels, and the stationarity requirement is written nowhere. Fix: guard (refuse or warn on a unit-root/trend test) and correct the docstring. Audit 26b S1 (no Diebold–Mariano test) still stands separately. | B |
| M2 | `compute_gaussian_synergy` silently drops constant streams from the O-information but not from `per_stream_contribution` or the metadata. | C |
| K1 | Dependencies are unpinned (`>=` only, no lock file); `one_off.yml` installs `numpy pandas openpyxl xlrd` without versions, and `openpyxl`/`xlrd`/`pdfplumber` (used by SMF and NHC scripts) are not in `pyproject.toml`. Frozen outputs are protected only by the weekly diff, and SMF/synergy are not in that diff (26b S5). | B |
| K2 | `analysis/dac_ozone.py` (run every week) still uses the old `emo/metrics/dac` path and the CSV files, not the standard JSON files (26b T2). The weekly run therefore never exercises `emo/dac_standard.py` on real files; only the unit test does. | C |
