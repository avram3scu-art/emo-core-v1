## PLAN 2.0: points, most serious first

- **P1. H4 can pass by procedure.** In the US, warnings and declarations are linked by formal procedure: a forecast can trigger an emergency declaration by rule (the legal basis is **unverified**; no source opened). A significant forecast-to-action coupling would then show that a procedure works, not that a mind emerged. H4 must ask for coupling **beyond formal procedure**, for example attention predicting action after forecast, severity and any rule-based trigger are controlled for. Otherwise a skeptic calls the result a straw man in reverse: the test is built so that ordinary bureaucracy passes it.
- **P2. "Mind" needs a null model.** Any responsive society runs some loop; calling it a mind adds content only if the links behave differently from independent agencies each doing its job. The plan should state that null ("independent agencies": each link responds to severity alone) and say that H4 and H5 must beat it.
- **P3. Severity confounds everything.** Attention, action speed and damage all rise with storm severity. Controls on intensity are necessary but may not be enough (damage depends on where a storm hits). The protocol (2.3) must name the severity measures before data are opened.
- **P4. Small n.** About ten seasons with all four links and a few US landfalls a season give perhaps tens of events (estimate, not counted). With controls, power may stay below 0.8 for years; the plan says so (§7) and the power-before-data rule enforces it.
- **P5. H1 is not evidence for the mind.** Improving forecast skill is NHC's known trend; it supports the predict link only. The plan should say H1 carries no weight on the mind claim.
- **P6. RDL 2.0 is thin.** A Brier-scored ledger tests forecasting, not remedy choice. That is honest, but "Choose" in the loop is then the weakest link; say so.
- **P7. Domain.** US-only and decision-based (declarations, not deliveries). H6 is correctly required before any general claim.
- **P8. Unverified sources.** Per-storm NHC verification, Tropical Cyclone Reports, warning times and FEMA's hurricane incident type are unverified (audit §6). Session 2.2 checks them before anything depends on them; correct order.
